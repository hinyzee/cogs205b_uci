Implement the BayesFactor class in bayes_factor.py for a binomial
spike-and-slab Bayes factor analysis.

Class structure:
- BayesFactor(n, k) — n is total trials, k is observed successes.
- Do NOT change the constructor signature. Do NOT add required arguments.

Methods to implement:
- likelihood(self, theta) — the binomial likelihood for k successes in n
  trials at success probability theta.
- evidence_slab(self) — the marginal likelihood under a slab prior on theta
  (uniform over the full parameter range).
- evidence_spike(self) — the marginal likelihood under a spike prior on
  theta (uniform over a narrow interval around 0.5, with width 0.06).
- bayes_factor(self) — the Bayes factor comparing the spike hypothesis to
  the slab hypothesis.

Constraints:
- Do NOT modify any file under tests/.
- Write ONLY bayes_factor.py. Do not create or modify other files.
- Use numpy and scipy only. No other dependencies.
- Use unittest conventions (this project does not use pytest).

Completion criterion:
- All tests in tests/test_bayes_factor.py pass when run with:
  `python3 -m unittest discover -s tests`
